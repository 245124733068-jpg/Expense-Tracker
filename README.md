# 💰 Expense Tracker

A simple and user-friendly **web-based Expense Tracker** built using **HTML, CSS, and JavaScript**. The application helps users manage their daily income and expenses and provides a clear overview of their financial balance.

## 📌 Features

* ➕ Add income and expenses
* 💵 Track total income
* 💸 Track total expenses
* 📊 Automatically calculate available balance
* 🏷️ Categorize transactions
* 📝 Add descriptions to transactions
* 📅 Select transaction dates
* 💾 Store transactions using browser **Local Storage**
* 🔄 Data remains available after refreshing the page
* 🧭 Simple navigation between Home and Dashboard
* 📱 User-friendly interface

## 🛠️ Technologies Used

* **HTML5** – Structure of the web application
* **CSS3** – Styling and responsive interface
* **JavaScript** – Application logic and transaction management
* **Local Storage** – Storing transaction data in the browser

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/Expense-Tracker.git
```

2. Open the project folder:

```bash
cd Expense-Tracker
```

3. Open `index.html` in your web browser.

You can also use **VS Code Live Server** to run the project.

## 💡 How It Works

1. Enter the transaction amount.
2. Select the transaction category.
3. Select whether it is **Income** or **Expense**.
4. Add an optional description.
5. Select the date.
6. Submit the transaction.
7. The application automatically updates:

   * **Balance**
   * **Total Income**
   * **Total Expenses**
   * **Transaction History**

All transactions are stored in the browser's **Local Storage**, so they remain available when the page is refreshed.

## 🎯 Purpose

The main purpose of this project is to provide a simple digital solution for tracking personal financial activities. It helps users understand their spending patterns and maintain better control over their income and expenses.
